## 主要修正与依据

- **01 · CDS-1 主入口（R01）**：去掉实心玻璃和贴脸背板。透明门厅、旋转门、侧门与金属框分离；窗后加入退后的墙面、顶棚、少量桌椅轮廓。
- **02 · CDS-1 夜间入口（U03 00:09）**：删除不透明的暖色发光覆盖板，灯光与简化纵深放在玻璃后。保留实体雨棚、横梁及门框。
- **03 · CDS-1 侧面首层（U03 00:52）**：首层清透玻璃、上层深色玻璃、层间不透明背板分别处理。灯、座椅和明暗块在窗后，颜色不照搬夜间过曝。
- **04 · 主楼玻璃与金属竖框（R02 实景分图）**：上层分为蓝灰与深色反光玻璃，银色竖框保持实体。玻璃不套墙砖像素纹理，框架保留低对比像素金属。
- **05 · 北侧配套楼大框窗（C07 / A06）**：大框窗由实心块改为玻璃面与浅凹槽，补上细竖梃和横框。遮挡面沿同类立面简化，不能视为逐窗核实。
- **06 · 礼堂入口及退台（C08）**：区分左侧退台玻璃护栏、后退入口、右侧反光玻璃及下层不透明设备门。大厅与台阶现有标高及比例仍有估算，未据照片重建完整室内。
- **07 · 连廊与圆形天井（C06 / A08）**：原实心护栏改成玻璃填板、金属扶手和细立柱；实体桥板与柱保持不透明。圆洞玻璃可透见后方立面，节点位置仍为估计。

## 确认程度

- **已确认**：R01 通过 CDS-1 门牌及校方栏目确认入口；U03 连续路线支持入口及该栋首层侧面透明玻璃；C08 的大厅外观与校园总览一致。透明玻璃与银色实体框、深色层间背板分别存在。A08 可见玻璃护栏、白色实体桥板和柱。
- **合理推断**：上层蓝灰/深色玻璃随光线呈不同反射；首层透视强于深色上层。邻近楼同类幕墙采用一致构造。反射用校园本身的单个低分辨率立方探针近似，非实测、非逐窗平面反射。
- **暂定**：未拍到的立面玻璃分布、窗格数量、房间背后的墙体及桌椅布置。2.4 m 门厅 / 2.6 m 立面浅纵深只是视觉布景，不是真实房间进深。连廊圆形节点的精确位置、礼堂现有台阶标高与入口比例仍待更清楚资料验证。体育馆入口仍为保守占位。

夜间视频的过曝不用于推断玻璃乳白、不透明，也不用于测透光率。R02 拼图内的规划效果图没有作为玻璃实景证据。同一照片转载和同一视频连续画面均不算独立证据。

## 实现与编辑

- `src/model/glazing.ts`：4 档玻璃（clear / office / reflective / guard），颜色、alpha、粗糙度、反射强度，以及浅纵深尺寸。**alpha 是美术调参，不是实测透射率**。
- `src/model/buildCampus.ts`：CDS-1 主体、透明入口、旋转门、保守简化门厅；`buildSite.ts`：其他楼、礼堂和连廊护栏。
- `src/voxel/materials.ts`：玻璃不再使用不透明墙面纹理，金属框使用低对比原创像素纹理。建筑其余像素风保持。
- `src/model/videoDetails.ts`：移除贴在玻璃前的实体夜景发光板；发光顶灯和浅纵深位于玻璃后。
- `src/viewer/glassEnvironment.ts`：仅在模型或昼夜变化时重拍环境探针，不逐帧拍立方图。
- 玻璃采用单层面片与 alpha PBR，关闭深度写入；不同朝向分开排序，同平面窗格合并。框架、立柱、横梁、背板均为不透明实体。旋转门的门扇分开排序。
- `src/exploration/navigation.ts`：沿用关闭的建筑/门碰撞，并为新增的玻璃护栏匹配碰撞体。透明材质不会取消碰撞。
- `src/viewer/export.ts`：重载 GLB 后恢复玻璃的 depthWrite 等渲染标志。标准 GLB 保留 alphaMode BLEND、双面和材质分类；本地实时环境探针不烘焙进 GLB，其他引擎应配置环境光及透明排序。

## 对照与运行

`npm ci && npm run play`，打开 http://127.0.0.1:5184/ 。在模型浏览的资料入口可打开玻璃对照页；直接链接为 `/references/glass/index.html`。

- 对照页：7 组实景—修改前—修改后，1600×1000。修改前由本轮改动前备份的建模源码重新渲染，当前运行时相机与照明一致。固定参数见 `evidence/glass/views.json`。
- `npm run check:glass`：分离材质、实际玻璃到背板的射线间距、关闭入口与玻璃护栏碰撞。
- `npm run check:all`、`npm run check:geometry`：现有控制、角色、协议及几何回归。
- `npm run export:glb && npm run validate:glb`：全校、无地面、七栋及其他现有资产导出、重载与 glTF Validator 检查。
- 实际浏览器行走和页面导出重载结果见 `evidence/glass/walking-checks.json`、`browser-glb-check.json`。画面错误检查见 `render-checks.json`。

## 仍有的差异

这是低模外观资产，不是建筑施工模型。浅纵深有意不延伸成可进入的室内；未复原实际办公室布局、家具型号或门厅拱顶曲面。大厅两侧台阶关系、标高及楼高仍沿用原有估算，不因玻璃修正而标为已核实。相机只近似参考角度。远处很密的细竖框仍可能出现轻微走样；透明面交叠多时受实时 alpha 排序限制。照片玻璃反射取决于实际天气和机位，模型的单探针不能完全复现。
