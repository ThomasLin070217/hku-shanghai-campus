# CDS-1 建模依据与暂定设计

核验日期：2026-11-12。此交付是用于校园探索游戏的正常状态外观资产，不是测绘、竣工或室内模型。当前聊天没有收到此前提到的三张海报原文件，未依据未见附件推定任何结构；后补 U01 卫星截图已纳入。

## 位置与身份链

1. HKU CDS 上海 Contact 页（T01）明确地址为上海浦东芳春路 500 号，和香港薄扶林地址分列。
2. Facilities 的 CDS-1 栏目照片（R01）右侧导视牌可读到 CDS-1，同时有中文校名及学院名。它是最直接的入口身份锚点。
3. 官方 Delta X 图集 R02 的两幅实景将高层 C 标为 CDS Main Building，A 是 Auditorium、B 是 Student Amenities & Learning Commons。利用门厅形态和楼群相对位置交叉对应 CDS-1；大台阶属于礼堂，未嫁接到主入口。
4. 教师公开主页 T02 写 CDS-1 / No.4 Building。其 590 Fangchun Road 与官网 500 号不一致，因此只采纳楼号旁证，地址差异保留。高德 POI 的“集电路305号”也只作为不同入口/标注差异留档，未假定已解决。
5. R04 设计方实景航拍中，靠礼堂的右后方相似塔楼与 C 对应。前景塔楼虽立面类似，但分段不同，未直接套用为 CDS-1。卫星 M01/U01 辅助校验右列中部楼与礼堂、下沉广场关系。M01 西侧“4号楼”属于邻近创芯天地，不能拿来证明 CDS-1。

## 已确认

- 深色玻璃幕墙，白/银灰色竖向构件；宽板和窄杆形成多层高的分段，横向细带划分层次（R02）。
- 短边中部内凹的连续玻璃区域，两侧外凸体块（R02；R04 屋顶轮廓支持）。
- 双层高门厅、平薄出挑雨棚、中央旋转门、两侧门、中文校名和学院名、入口右侧 CDS-1 导视牌（R01、R03 00:26）。
- 入口铺装近乎平接，只设浅门槛；两侧绿化。两侧细杆按安防/照明杆简化，不当成已确认的雨棚结构柱。
- 邻近存在礼堂、大台阶和下沉空间；它们不等于 CDS-1 入口或已证实连廊。

## 合理推断

- 以约 60:45:66 的宽深高关系作为游戏原型起点。对照 R02 透视轮廓、R04 航拍及 M01 卫星粗核对，不宣称精密摄影测量。
- 主入口位于所见长立面的中部区域，局部坐标 +Z 朝入口。没有把 +Z 宣称为测量真北。
- 主体用两段矩形翼体和内凹中央连接体组成，保留实景可见轮廓；这只是外形构造方式，不表示真实结构体系或室内分区。
- 屋顶平屋面、围护与设备体块可见，设备细节用少量几何代替。

## 美术与几何约定

- 低模、无照片贴图；玻璃用不透明的蓝灰 PBR 材质表现，避免游戏视角下看穿到不存在的室内。
- 文字是挤出的三维几何，CDS-1 导视与入口中文可随 GLB 导出；字体近似，未伪造校徽。
- 屋顶和隐藏面采取保守简化；窗后没有房间、楼梯、碰撞导航网格或虚构内部。
- 主楼、玻璃、立柱/竖向板、横向分隔、入口、雨棚、屋顶、标识分别命名。重复件在同一语义组内按材质合并降低 draw call，仍为真实几何。
- 场景、相机、灯光、UI 与资产生成分离；GLB 不包含预览灯光、相机或界面。

## 主要差异与待补拍

模型保留了主体、凹槽、分段立面和主入口的可辨识特征，但未逐窗校准、未还原玻璃反射环境与室内、屋顶设备和周边空间只达到原型精度。对照图在 `../assets/comparison-board.jpg`。

最有价值的 3 个补拍角度：

1. **入口正前方后退到能拍全屋顶与左右角的位置**：画面带 CDS-1 牌，最好加一张可测量的门宽或柱间距，用于统一尺度、入口占比和层带。
2. **入口左、右各 45°，从地面连续拍到屋顶**：带转角与邻楼/连廊接点，补全进深和目前简化的背侧面；一侧一组即可。
3. **经许可的高处斜俯视或屋顶全景**：带目标楼和礼堂共同入镜，核实内凹轮廓、机房高低、设备排布和连廊是否与主楼实际连接。
