## 0. 一句话

**巡检任务提交档案 001 的那一刻，整座校园断电。唯一还亮着的终端，是大堂那面巨大的键盘墙——它自检失败：有一行的字是错的，缺一个键。**

玩家要用现有的 F 交互与 C 电脑把这两面墙修好：抠下墙前凳子上的 X 键帽 → 没电 → 走完整条走廊，把另一面能转的像素墙转回正确状态 → 回来拧锁孔、按顺序校验三颗功能键 → 墙滑开。

**两面墙是同一台机器的输入与显示**：键盘负责输入，像素墙负责显示校园各处的供电状态。同材质、同配色（浅木 + 墨绿）。这正好落在现有工程"像素风"的审美里，不需要写实贴图。

## 1. 怎么接进已有故事线

现有 v9 的主线是一条**巡检**：三个地标 → F 拾取绿色记录牌 → 1 装备 MacBook → C 打开电脑 → 任务页同步 → 解锁档案 001《未完的地图》。线索来自 `src/gameplay/survey.ts` 与 `landmarks.ts` 的 `campusLandmarks()`。

谜题**不替换这条线，而是接在它后面**，成为任务页的第二条：

| 阶段 | 玩家看到 | 承接已有的东西 |
|---|---|---|
| 前置 | 三条记录集齐，任务页提交成功，档案 001 打开 | 现有 v9 全流程，一字不改 |
| 触发 | 提交成功后的第一次面板关闭，全校园灯光熄灭、天空压暗、边界出现半透明穹顶 | 现有光照/天空系统 + 一个半球体；"断电"设定 |
| 任务 002 | 任务页新增「补键」：`大堂终端离线；备用电在走廊那头` | 新增 TASK2，additive |
| 关 1 | 大堂键盘墙：抠键 → 插锁孔 → `NO POWER` | 新增 W01 / P01 |
| 关 2 | 走廊像素墙：把转反的四格方块转回来 → 三位数 → 通电 | 新增 W02 |
| 收尾 | 回键盘墙：拧半圈 → 点亮三颗功能键 → 墙滑开 | 新增 W03（滑门） |
| 结局 | 进入墙后空间，终端重启，灯光与穹顶复原，档案 002 解锁 | 现有档案系统 |

**故事锚点**（沿用群里已经说定的，不另起世界观）：

- 开幕式那一刻整栋楼照明坏了 → 断电即开场
- 键盘的按键可以拆下来 → 抠键帽
- 钥匙后面有一台超算 → 墙滑开后的空间
- AI 造了一个罩子把校园和外界隔开 → 穹顶

**现有实体一律不动**：B01–B07、R001…、A…、S001、L001（狮子）保持原编号与几何。狮子在断电过场里只出现一次（远处转头），不加任何玩法，也不做战斗。

## 2. 现场依据（照片与视频）

### 大堂键盘墙（11-15 21:37）

- 四行巨型圆形键帽，浅木底板 + 深蓝底，正交网格，无错位
- 第二行是标准 `QWERTY`：`Q W E R T Y U I O P [ ] \`
- 第三行本该是 `A S D F G H J K L`，墙面是 **`I S L O V E J C D S`**（10 键，比标准多 1）
- 第四行 `Z X 〔黑色锁孔〕 B C N …`，字母整体右移一位——**缺一个键**
- 黑色锁孔是凹盘，中间一根可转金属柱
- 墙前有一颗键帽造型的白色小凳，顶面刻 **X**
- 左右两列是深蓝功能键：`←`、`Female Restroom`、`Caps Lock`、`Shift`、`Return`

### 走廊像素墙（11-16 00:18 视频）

- 两色**立体方块**拼的像素网格（浅木 + 深墨绿），块间有缝、略微凸出
- **方块可以旋转**：不是印上去的画，朝向决定这一格的浅/深——本质是 1 位机械显示器
- 沿走廊铺满，一段视频装不下整面墙
- 走廊尽头：亮着的窗、深色门洞、一个白色开关面板
- 目测 30–40 列 × 12–15 行（待现场数准）

## 3. 世界里的三个新实体（建议编号）

按 `AGENTS.md` 的编号规则新增，全部 append-only，已有 `authorKey` / `userData.sceneId` 不变：

| 编号 | 名称 | 位置建议 | 尺寸（世界单位） | 几何 |
|---|---|---|---|---|
| **W01** | 大堂键盘墙 | B04 门厅内侧墙面，正对入口 | 12.0 × 3.6 × 0.25 | 底板 1 块 Box + 4 行 × 12 列 = 48 个 `CylinderGeometry` 键帽（r 0.13, h 0.06），键面用 CanvasTexture 画字 |
| **W02** | 走廊像素墙 | B04 走廊一侧整面，长 16.0 | 16.0 × 3.0 × 0.2 | `InstancedMesh`：32 列 × 12 行 = 384 个 Box（0.18³），两套材质（浅木/墨绿），每块 `userData.cell` |
| **W03** | 滑门 + 墙后空间 | W01 正中 | 3.0 × 3.0 | 两块可位移 Box；墙后 6×4×4 空腔，内置 4 台机柜 Box |
| **P01** | 键帽小凳 | W01 前方 2.5 | 0.5 × 0.45 × 0.5 | Box 座 + 四条腿 + 顶面 X 的 CanvasTexture |

**总量**：48 + 384 + 约 30 = 约 460 个可实例化物体，其中 384 个共用一个 `InstancedMesh`。现有工程已经在渲染体素校园，这个量级不构成性能问题。

**风格**：全部程序化几何 + CanvasTexture，不引入外部模型；两色取现场照片的木色与墨绿。这符合 `AGENTS.md`「保留当前像素风」，也避免上模型贴图的返工。

## 4. 关 1 · 键盘墙（W01 + P01）

所有交互都走现有 **F 交互**（范围 2.7、视线锥 dot ≥ .90，与 v9 记录牌同一套判定），解谜界面走现有 **C 电脑面板**新增的第 4 页「终端」。

### 步 1 · 抠键（P01）

- 走到 P01 前按 F → 拾取 `keycap-x`（现有背包系统，占 1 格）
- 凳面留下一个方形空槽；P01 随后滑到 W01 墙脚

### 步 2 · 插不进（W01 锁孔）

- 走到 W01 锁孔前按 F → 终端页自动打开，提示「插入 X 键帽」
- 插入 → 墙面弹 `NO POWER`，电量格 0/5
- 终端页给一行字：「备用电在走廊那头。」任务 002 目标点切到 W02

### 步 3 · 通电后：拧 + 校验

回到 W01：

1. **拧**：终端页出现一个可拖动旋转的凹盘控件，把键帽转到四个方位里唯一能卡住的那个（答案由 W01 键面形状决定），拧半圈 → 墙面从暗变蓝，四行键依次点亮
2. **校验**：按顺序按 F 点亮三颗功能键（`←` → `Caps Lock` → `Shift`）
3. 顺序线索就在墙上：第三行 `I S L O V E J C D S` 多出来的那个 `S` 在第 2 格——这就是第一条指令，往下由左列功能键自上而下推出来。**玩家必须抬头读 3D 墙面，不能在面板里瞎点**
4. 点错扣一格电（共 5 格）；扣完退回「拧」这一步重来，不重开存档

## 5. 关 2 · 走廊像素墙（W02）

- 终端页只给**四个格子坐标**（"第 7 列 第 3 行"这样），不给图
- 墙上有四格朝向不同——被转反了，颜色不对
- 走到每一格前按 F：该方块绕 Y 轴转 90°，200ms 补间 + 一声轻响
- 四格全正 → 深色格连成一条线，露出**三位数**（画在四格对应的键面上）
- 三位数输进终端页 → W02 整面墙按列依次亮起 → 电量 5/5，任务目标点回到 W01

**备选 A（不旋转，只读）**：读三段连续深色台阶的格数（各 1–9），输三位数。少 3 小时工作量。
**备选 B（最保险）**：终端页给「靠窗 / 中段 / 靠楼梯」三段，问哪一段深色最多。答案三选一。

三档只差"要不要让方块真的转"。W02 的旋转本来就是这关的卖点——**3D 才做得出来的那一下**，建议优先做主玩法。

## 7. 数值与节奏

| 项 | 值 |
|---|---|

## 10. 开工前要确认

1. **W01 墙放哪个空间**：B04 门厅内侧够不够 12 单位宽（需要一次实测）

4. **走廊像素墙的列数行数**：现场数准（32×12 是占位值）
