# MacBook Air 与 Vibe Console 交付说明

## 试玩

关卡选择页保留原有入口。桌面浏览器建议使用键盘和鼠标。开发环境运行 `npm ci` 和 `npm run dev`，在终端给出的地址后加下表中的查询参数。

| 入口 | 能体验的流程 |
| --- | --- |
| `?experience=lion-boss` | 从草坪维护区打开 MacBook，编程、实测、部署，关盖后主动施放并完成 L001 三步修复 |
| `?experience=opening` | 在 6 号楼演示桌按 F 取得 MacBook Air，用快捷栏装备并按 C 打开。V 切换第一／第三人称。帷幕、警报和确认均读取本章状态 |
| `?experience=survey` | 按 C 打开巡检电脑。在地图查看位置，在 Files 阅读搜集的记录，在 Mission Logs 同步校园数字档案 |
| `?experience=macbook-lab` | 开发／审阅模式专用。演示超算接入通知、三个技能竞争两个槽位，以及机器人允许和拒绝的指令 |

### 草坪上的第一局

1. 在维护区打开电脑，点 Dock 中的 **Vibe Console**。选择 **System Freeze**，输入「狮子在 8 米内蓄力冲撞时，我按技能让它短暂停机」。点「生成规则」，在右栏确认触发条件、距离、持续时间和冷却。
2. 点「测试技能」。正确时机应允许施放，错误时机和超出射程应拒绝。三项均符合预期后点「编译并部署」，等左栏出现已装备快捷键。改动指令后需要重新生成、测试和部署。
3. 为 **Robot Hijack** 输入「等狮子挥完爪，我按技能让阿树从右侧牵制它」。重复测试和部署，确认规则保留了右侧参数。合上电脑回到草坪，按 HUD 上显示的键施放，默认分别为 Q、R。
4. 第一节点在冲撞蓄力时按 Q，进入光圈长按 F 验证维修身份。第二节点先避开扇区，在挥爪收招时按 R，等阿树把狮子引开，再长按 F 隔离感染指令。第三节点再次用 Q 创造窗口，长按 F 恢复识别配置。

节点只在修复提交完成后记入存档。受击会扣心并返回检查点，重新打开电脑沿用维护区限制。HUD 会显示目标、时机、冷却和施放结果。

## 桌面与接入情况

七个 Dock 应用共用实体设备、窗口管理和关卡数据。窗口可拖动、置前、关闭、最小化和恢复。Esc 每次退一层。打开电脑时释放鼠标并暂停角色输入，关盖后恢复游戏视角。聊天和技能草稿支持切换窗口，旧草坪设备和已部署规则可继续载入。

| 功能 | 当前真实数据或行为 | 联调边界 |
| --- | --- | --- |
| 桌面阶段 | 开场读取电脑拾取、帷幕、警报和确认事件；监控显示连接、设备供电和当前心值 | 正式 B4 备用超算尚未接入。到达门口仍需授权。草坪独立入口显示「本地维护」，可直接体验已有的两个技能 |
| AI Assistant | 支持 Ollama 或同源模型代理、Markdown、代码复制、停止、重试、按设备保存历史。故障时显示离线来源，按当前任务给建议 | 公开静态试玩使用离线应急助手。本次没有可用的真实模型实例；成功响应格式使用测试服务验证。需要认证的模型在代理服务端配置密钥 |
| Vibe Console | 草坪复用原有自然语言解析器、施放验证和战斗效果。预览、有效／无效场景测试、安装回执、装备槽和 HUD 串联 | 两个真实项目为 Freeze 与 Hijack。Ghost 在草坪可写草稿，正式部署需要上游实现。真实草坪未提供算力计量，界面显示「未提供计量」 |
| Robotics | 开场显示巡逻设备的真实状态。草坪返回阿树遥测，L001 只开放观测。牵制由原战斗规则校验时机和权限 | 超算接口演示中的测试机器人允许 Scan、拒绝 Follow。演示的资源、指令与技能回执只在当前演示页有效 |

草坪规则编译器按原有词法识别招式、效果、距离和牵制方向。持续时间和冷却由战斗规则给出。团队接入可按设备 ID 调用 `registerCampusComputeSource` 注册实时会话，接口定义见 `src/lionBoss/deviceServices.ts`、`src/lionBoss/consoleService.ts`。提供方负责从正式存档恢复授权、实施规则、返回资源／槽位和施放结果。关闭、刷新和权限变化后，桌面重新读取提供方状态。

## 验证记录

- Chrome 实测开场 B6 真实拾取，两个视角的开盖、关盖、鼠标释放和输入隔离。B5、B4 使用剧情检查点验证警报确认和门口权限。
- 草坪用键鼠输入两条指令，受击由 10 心降至 8 心，逐点修复。在 2/3 刷新，生命、设备、快捷栏和右侧牵制规则保留。完成第三步后显示「L001 已安全关机」。
- 巡检验证档案不足时提交被拒、已收集文件入口、地图和返回游戏。审阅入口验证 Ghost 与 Freeze 占满两个槽、第三个项目被阻止、Scan 收到回执、Follow 被禁用。
- 桌面和 Vibe Console 已在桌面及 375 像素宽视口验证。模型端不可达、重试、请求中断、窗口切换草稿和消息来源均已检查。
