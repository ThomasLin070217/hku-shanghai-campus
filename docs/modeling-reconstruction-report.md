## 视觉复现与运行

每栋楼提供正、左前、右前、入口附近和玩家眼高五个视角。缺少实测入口的楼用现有模型门区或正面近处为取景点。补充北侧高位及雅堂前后状态。总计 38 个机位／状态，每个都有同参基线和新图，960×600。正视和斜视 FOV 52°、玩家眼高与雅堂 FOV 70°。照片和游戏图用于特征对照，照片焦距及测站不可知；游戏照片相机为独立审阅入口。雅堂机位只画静态场景与道具，NPC 离场由开场运行测试验证。

通过 `npm run dev -- --port 5191` 启动开发服务后，可以在项目目录运行：

```powershell
node scripts/capture-reconstruction.mjs 'C:/Program Files/Google/Chrome/Application/chrome.exe' http://127.0.0.1:5191/evidence/reconstruction/camera.html evidence/reconstruction/latest --smoke
```

Chrome 实际打开了开场、校园巡检和体育馆三条入口，见 [运行检查](../evidence/reconstruction/after/runtime-smoke.json)。通过 `check:all`（含生产构建）、`check:opening`、`check:lion-boss`、GLB 导出和 glTF 校验。20 个 GLB 校验均 0 错误、0 警告。主校园与开场目录分别重新导出；与基线目录逐 ID 比较，18,346 和 18,337 个索引项均无新增或删除。
