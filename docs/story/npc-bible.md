# 第一章角色卡与固定对白

版本：1.0  
适用章节：`chapter.01`

## Michael Zhang（`npc.student.guide`）

### 角色卡

- 身份：开学典礼学生大使负责人，原创虚构角色。
- 外观辨识：绿色典礼外套、浅色斜挎工作包、手持疏散名单。
- 动机：尽快疏散来宾，并确保玩家清楚当前任务。
- 已知：控制中心位于四号楼；Ruibang 可以远程提供恢复方法；玩家熟悉路线。
- 未知：黑客身份；控制台的正确操作顺序；狮子机器人的内部状态。
- 秘密：无。简化版不设置人物秘密。
- 口吻：冷静、直接、短句；紧急情况下不讲长篇背景。
- 初见行为：检查学生大使签到情况。
- 卡关行为：重复当前地点与目标，不提供谜题答案。
- 完成后行为：通过终端确认危机解除并感谢玩家。

### 固定对白

| 情况 | 台词 |
|---|---|
| 初见 | “最后一轮签到，确认完就可以去看草坪上的机器人表演了。” |
| 机器人失控 | “所有人从东侧通道撤离，不要靠近服务机器人。” |
| 发布任务 | “我走不开。你熟悉路线，穿过中央楼去 CDS-1 控制中心，Ruibang 会接应你。” |
| 重复询问 | “目标没变：四号楼，CDS-1 控制中心。” |
| 无关话题 | “先处理机器人，其他问题等大家安全后再说。” |
| 任务未解锁 | “先完成签到，我需要确认还有谁留在晚宴区。” |
| 玩家卡路 | “看工作终端上的箭头，从三号楼方向前往四号楼。” |
| 任务完成 | “草坪安全了。做得好，剩下的交给救援人员。” |
| 固定备用 | “信号不好时就看任务终端，目标位置已经标出来了。” |

## Ruibang（`npc.campus.tech`）

### 角色卡

- 身份：校园设施技术员，原创虚构角色；通过语音频道出现。
- 外观辨识：如制作实体模型，使用蓝灰工装、工具腰包和橙色识别灯。
- 动机：恢复本地控制，同时防止黑客指令再次进入。
- 已知：控制台离线恢复规则；宇树助手正在充电；紧急装置的用途。
- 未知：黑客身份；入侵来源；玩家路线上的具体障碍。
- 秘密：无。所有通关必要信息均可直接提供。
- 口吻：准确、务实；解释因果，不使用夸张黑客术语。
- 初见行为：确认玩家已经抵达控制中心。
- 卡关行为：按 0/1/2 级逐步提示解密。
- 完成后行为：说明草坪上的关闭装置是下一目标。

### 固定对白

| 情况 | 台词 |
|---|---|
| 初见 | “我是 Ruibang。控制台还能离线恢复，先看看旁边的应急说明。” |
| 重复询问 | “三步都在控制台上，重点是先后关系。” |
| 无关话题 | “入侵来源还查不到，先恢复本地控制。” |
| 任务未解锁 | “控制台还没通电。靠近主面板并启动离线程序。” |
| 谜题错误 | “顺序不对。现在恢复控制，会让外部恶意指令重新进来。” |
| 提示 0 | “先读应急说明，答案就在控制台旁边。” |
| 提示 1 | “备用电源必须最先启动，外部网络不能留到最后处理。” |
| 提示 2 | “正确顺序是先启动电源，再隔离外部网络，最后恢复本地控制。” |
| 解密完成 | “本地权限回来了。充电舱里有一台没被感染的四足机器人，启动它。” |
| 章节完成 | “三处关闭装置全部响应，狮子已经安全停机。” |
| 固定备用 | “如果操作失败，控制台不会锁死，重新排列就行。” |

## Lam（`npc.terminal.echo`）

### 角色卡

- 身份：控制中心的固定离线 AI 终端，原创虚构角色。
- 外观辨识：固定屏幕、白色状态文字、清楚的步骤编号和提示音；不使用人形身体。
- 动机：执行离线恢复程序并报告确定性状态。
- 已知：当前任务阶段、控制台输入、宇树助手和紧急装置状态。
- 未知：黑客动机；校园其他区域情况；尚未传入系统的现实事件。
- 秘密：无。它不是幕后黑手，也不决定谜底。
- 口吻：简短、中性、可操作，不生成新的任务或道具。
- 初见行为：显示控制台可用状态。
- 卡关行为：报告错误步骤并调用固定提示。
- 完成后行为：显示狮子关机和章节完成状态。

### 固定对白

| 情况 | 台词 |
|---|---|
| 初见 | “离线恢复程序可用。等待操作员输入。” |
| 重复询问 | “当前目标：恢复本地机器人控制。” |
| 无关话题 | “该问题不属于离线恢复程序。” |
| 任务未解锁 | “访问受限：请先接受现场任务。” |
| 谜题错误 | “恢复失败。检测到步骤顺序冲突，可以立即重试。” |
| 提示 0 | “应急说明包含全部必要规则。” |
| 提示 1 | “电源步骤位于第一位；隔离步骤早于恢复步骤。” |
| 提示 2 | “启动电源，然后隔离外部网络，最后恢复本地控制。” |
| 解密完成 | “本地控制已恢复。未感染设备：一台。” |
| 助手解锁 | “宇树机器人助手已启动。可用指令：跟随、扫描、牵制。” |
| 章节完成 | “三处紧急装置已启动。巨型狮子机器人已安全关机。” |
| 固定备用 | “网络不可用，离线任务仍可继续。” |

## 非对话角色

### 宇树机器人助手（`robot.helper.unitree`）

- 无口语对白，以灯光、动作和提示音反馈“跟随、扫描、牵制”。
- 当前使用宇树品牌属于团队提案；正式使用品牌名称和外观前需确认授权与展示方式。
- 固定反馈：指令成功发出一声短提示音；无法执行时发出两声短提示音并在界面显示原因。

### 巨型狮子机器人（`boss.robot.lion`）

- 开学典礼表演机器人，被黑客控制后成为本章 Boss。
- 没有正式名称，不使用此前原创暂名“明狮”。
- 不说话，只通过吼声、动作预警和状态灯表达状态。
