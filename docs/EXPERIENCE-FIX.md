# 校园体验修复 · 2026-11-14

本轮在现有 Vite + TypeScript + Three.js 工程直接修改。查看实际图片后补植物，统一步态与音效事件，修正狮子尺寸参数，保留既有玻璃、任务、背包与原生 AI 接口。

## 启动与查看

```sh
npm install
npm run play
```

打开 `http://127.0.0.1:5184/`。`npm run play` 启动前端及本机 AI 服务；若已有实例运行，直接打开即可。生产预览：`npm run build` 后 `npm run preview -- --port 4174`。

页面“验收档案”打开 `evidence/experience-fix/index.html`，包含同位置前后图、人物动态、狮子同框、带声录屏和运行记录。

## 原因与修复

- **头部与行走：** 原始动画的头部扫描轨道在站立/行走时约 15°、奔跑约 30°；根节点还带有局部上下位移。现在保留原几何与骨架，由一处姿态代码控制，取消原头部轨道，世界位置只由物理控制器驱动。身体小幅前倾，头部抵消该倾斜；无随机看向摄像机。腿部、足底接触、步态相位依据实际移动距离，持电脑只修改手臂及手部插槽。第一人称仍使用独立的固定眼高锚点。
- **脚步：** 原单一低频合成音替换为 CC0 硬质铺装/草地各五种短采样。统一步态事件只消费一次，角色隐藏、第一/第三人称共用。落地单独一次，带短暂脚步抑制；顶墙没有实际位移时不发声。使用真实落脚位置与相机听者位置衰减。
- **环境：** 原 12 秒合成底噪改为处理过的 45 秒真实公园风声录音，交叉淡化循环，低音与尖锐高频收敛。它是通用替代音，不是 HKU 现场收声。单个背景源有明确生命周期；暂停淡出、隐藏挂起、恢复继续原源。环境/脚步/界面/音乐分别调节。当前没有音乐资产，音乐通道默认 0。
- **音量缺陷：** 实际复测发现挂起的 AudioContext 中连续调节滑块会积累旧自动化值；现在清理旧调度再设置增益，恢复后各通道实际生效。
- **绿化：** 门前等高灌木改为分层灌木与地被，楼侧绿篱加长，广场外围补种植带，狮子草坪外围补疏冠树和低植物。位置由确定的种植区域出发，精确分布仍标注为估算；主路、坡道口、门前留空。树干和花坛边缘有碰撞，叶簇不阻挡。重复几何按材质合并，不逐片叶子增加独立绘制对象。

## 狮子尺度

世界单位为米，原导入没有厘米/米的百倍错误；发现的是“配置高度”和实际网格边界不一致，以及旧比例在场地中偏小。本体统一比例调整，独立低支撑调整，未缩小玩家或放大镜头来伪造尺度。

| 项目 | 修改前实际边界 | 修改后 |
|---|---:|---:|
| 本体宽 | 3.075 m | 3.908 m |
| 本体高 | 4.565 m（配置 4.8） | 5.800 m |
| 本体深 | 1.752 m | 2.226 m |
| 独立支撑宽 × 高 × 深 | 无独立对象 | 3.5 × 0.12 × 2.0 m |
| 本体加支撑总高 | 4.565 m | 5.920 m |
| 本体三轴缩放 | 相同比例 | 相同比例，整体约增大 27.1% |

新值是**暂定美术尺度**。U05 三个角度支持“大型坐姿狮子、无高石台”，用户也反馈实物更大，但没有同距离已知尺寸的参照物，不能称已测准。支撑为低矮简化结构，并非确认现场有此石台。地面高 0.13 m 不计入狮子总高。位置仍为 (0, 76)，朝向未改变。

玩家标称高 1.8 m，含头发静态外包围约 1.805 m；眼高 1.64 m。截图 `lion-first-person.png` 摄像机世界 y=1.77（草地 0.13 + 眼高 1.64），72° FOV、水平视线；第三人称使用正常跟随相机 6.8 m 距离，完整人物和狮子同框。镜头参数同时存于 JSON。

## 已执行验收

1. 先运行旧版，保存固定相机截图、原步态视频、原音源和模型边界；旧代码备份在 `work/experience-fix/before-src`。
2. 简洁人物预览真实播放站立、步行、奔跑、起跳/落地和手持电脑，保存前后动态录像，抽取连续时间帧检查头部与腿部。
3. 校园连续录屏由**外部 Node 脚本通过 HTTP 原生动作接口**驱动，普通物理更新消费动作；录制期间没有改坐标、瞬移或离线合成场景。录制前只放置安全验收起点。视频声音来自游戏最终混音，不是后配音。
4. 0–3 秒站立/铺装；3–9 秒草地步行/奔跑；9–11 秒停止/跳跃落地；11–20 秒返回楼侧并顶玻璃；20–26 秒切第三人称/持电脑行走；26–45 秒绕狮子与边缘绿化；45–50 秒观察、跳跃中切换视角并落地。完整原始视频约 68 秒，便于查看的 MP4 仅去掉末尾静止等待，保留前 50 秒连续操作。
5. 实际记录：铺装脚步 32 次、草地脚步 117 次、落地 2 次；站立、停止、腾空及顶墙段新增脚步均为 0。全程一个背景源、一次启动。录音无削波；立体声实际混音已输出并执行 `afplay` 播放。
6. 另用实际 W、V、E、C、Esc 按键检查松键停止、连续六次切视角、背包、电脑和暂停；复测四路音量；返回安全位置不新增背景源。AI HTTP 接口可控制，人工 W 接管后迟到命令返回 `stale_epoch`。
7. 自动检查覆盖 30/60/120/240 fps 步态事件一致，头部稳定、足底接触、落地单次；东西步道与狮子前草坪路线畅通；任务、存档、背包、玻璃碰撞、物理及地图比例回归通过。GLB 已重新导出并校验。

**试听限制：** 已实际启动浏览器声音和系统播放，并保存带声录屏；当前工具明确不支持音频输入，无法让我主观辨听音色。因此“音色是否自然、是否符合校园记忆”的主观试听仍未验证，不能用波形或触发检查替代。用户可以直接播放验收页的视频/音频评估，不必重新操作全流程。

## 集中参数与素材

- 角色/头部/持物姿态：`src/characters/character.ts`；步距、混合、落地抑制：`src/characters/gait.ts`。导出动画由 `bakedClips.ts` 从相同姿态烘焙，不再导出原大幅摆头轨道。
- 走 2.6 m/s、跑 5.2 m/s、眼高、物理、出生偏移：`src/exploration/config.ts`。
- 狮子本体/支撑尺寸、位置、朝向：`src/model/lionParameters.ts`。碰撞随尺寸更新。
- 新增种植带/树高/冠幅/位置：`src/model/landscapeDetails.ts`；侧面绿篱长度：`src/model/videoDetailsParameters.ts`。
- 音量默认值：`src/gameplay/save.ts`；源、衰减、循环、混音：`src/gameplay/audio.ts`；处理脚本：`scripts/prepare-campus-audio.py`（需要 FFmpeg/numpy 或设置 CAMPUS_FFMPEG）。原采样授权：`assets/audio/SOURCES.md`。
- 对应参考与未确认项：`references/experience-fix/REFERENCES.md`。
- 自动检查：`npm run check:experience`；完整回归：`npm run check:all`。外部路线脚本：`scripts/verify-experience-browser.mjs`，先在页面开启 AI，再从合适起点执行；它本身不会传送角色。

## 保留的不确定性

狮子与底座、树高和精确株距仍为估算；夜间视频不能准确确认植物品种、颜色和所有角落。校园水平标定保留原卫星核对结果，楼高未新取得实测。背景录音为通用风声，尚不能代替白天校园现场氛围。关卡仍只探索室外。
