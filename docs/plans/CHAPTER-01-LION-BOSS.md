# 第一章 L001 草坪 Boss 关卡方案

## 试玩入口

切换到 `codex/lion-model` 分支。首次拉取后，在仓库根目录运行 `npm ci` 安装依赖，再运行 `npm run play`。用电脑浏览器打开 [L001 草坪试玩](http://127.0.0.1:5184/?experience=lion-boss)。开场完成页也有草坪试玩按钮。独立入口直接从维护区开始，已完成开场的玩家沿用领取的 MacBook。

点击「打开 MacBook」或按 C，在校园电脑桌面或程序坞打开「技能工作台」。给两个槽位分别输入意图或改写示例，生成规则、核对条件、测试并部署。工作台可返回桌面；点「合上电脑」后选择「进入草坪」。用 WASD 移动、拖动鼠标转向。默认 Q 打断冲撞蓄力，R 在挥爪收招时召唤助手，窗口打开后进入当前节点光圈长按 F。暂停后可回维护区调整技能或更换按键。

从开场完成页接入时，草坪沿用开场的心值、MacBook 实例、背包布局、视角、音量和控制设置。E 打开校园背包，数字键切换快捷栏。草坪检查点单独保存修复进度、技能、心值和物品栏位置。电脑的地图、Recovery Agent 和终端会显示草坪任务信息。

**玩家目标**　带着从六号楼取得的 MacBook，在四号楼准备两项反制技能，到校园草坪迎战 L001。玩家观察招式、走位并主动施放技能，让狮子的本地控制进入可修复状态，再提交修复。三步修复完成后，校园系统撤销对玩家的入侵判定，狮子行礼并安全关机。

## 剧情与场地

校园的门禁、机器人与应急控制都属于同一套计算系统。草坪上的 L001 是负责抵御实体入侵的安防机器人，平时也能执行典礼动作。玩家在四号楼重启本地控制并开始清除病毒时，受感染的防御系统把这次维修判成入侵，派 L001 封锁草坪。四号楼已经准备好干净的恢复配置，但狮子持续执行防御命令。玩家需要打断它的防御动作，才能把修复逐步写入草坪端的本地维护节点。

沿现有开场从四号楼门外接续。通过 `opening.building4_reached` 或读取已完成的开场存档，继承故事标记和同一台 MacBook 的实例 ID。完整关卡保留四号楼的「启动电源 → 隔离外部网络 → 恢复本地控制」排序和宇树助手交接。首版沿用实装开场的 2030 年及路线，第一章草案的 2040 年和三号楼过渡留待统稿。

以既有 L001 底座为开战位置。草坪入口设维护区，出入口处可清楚看到狮子和当前维护节点。保留草案的三处装置位置概念，改作依次解锁的本地维护节点。每处节点附近应有足够空间横移躲冲撞、后撤躲挥爪。具体点位由走测确定。

依据：[第一章剧情](../story/chapter-01.md)、[开场交接](../opening/HANDOFF.md)、[开场场景编号](../../assets/scene/opening-major-index.md)、[狮子配置](../../src/model/lionParameters.ts)。

## MacBook 技能工作台

**MVP 采用战前编写、战中即时施放。** 玩家在安全维护区按 `C` 打开已取得的 MacBook，进入桌面「技能工作台」，制作并部署两项技能。进入草坪后，MacBook 技能栏映射到两个可重绑的施放键（原型用 `Q`、`R`，接线前核对现有键位）。技能只在玩家按键后尝试执行。每步修复后可回维护区重编、重测并部署，恢复交战时从当前步骤起点开始。

1. **描述意图。** 工作台给出目标和可用能力的短说明。技能一可以写「我按下技能时，如果狮子正在蓄力冲撞，就让它短暂停机，打断这次冲撞」。技能二可以写「我按下技能时，如果狮子刚挥完爪，就让阿树从侧边吸引它，给我时间提交修复」。
2. **查看生成规则。** 逐行显示「玩家按下 → 检查目标与招式阶段 → 执行效果」，同时列出范围、持续时间和冷却。例如技能一显示「L001 在 8 米内且处于冲撞预警 → 取消本次冲撞并进入短时维护状态」。技能二另显示助手就绪及牵制点。范围和强度由关卡提供，玩家可以改写技能目标、触发条件和助手点位，在预览里确认修改。
3. **运行测试。** 回放一段固定的狮子招式，玩家按「模拟施放」。成功时显示取消命中判定或切换目标的那一帧，以及维护窗口何时开启。失败时显示具体原因，例如「冲撞方向已锁定」或「助手仍在冷却」。每项技能都能跑一个有效场景和一个不匹配场景，附可重播时间轴与范围示意。测试与实战共用规则求值器，草坪状态保持冻结。
4. **部署到槽位。** 把已通过测试的版本装入槽位，看到「已部署」和对应键位。编辑会使新版本的测试过期，旧部署继续可用，直到新版本测试通过并替换。部署只装载技能，玩家重新进入草坪后仍要自己按键选择时机。

首版用离线意图解析支持两种技能、明确的招式阶段和少量合法牵制点。支持改写示例与中英常见表达，点位模糊时请玩家确认，失败时保留输入并标出无法识别的条件。生成物是游戏内的有限规则配置。技能工作台复用开场电脑的装备、桌面和暂停交互。

依据：[开场电脑](../../src/opening/macbook.ts)、[装备与交互](../../src/opening/experience.ts)、[游戏固定步进](../../src/exploration/game.ts)。

## 实战反制

| 狮子招式 | 玩家看到什么 | 躲避与主动反制 |
| --- | --- | --- |
| 向前冲撞 | 狮子压低身姿，地上出现带箭头的冲撞走廊，伴随低音。预警约 1.25 秒，结束时锁向并冲出。 | 在预警结束前、有效距离内按短时麻痹，立刻取消这次冲撞并打开维护窗口。错过时机就横移出走廊，等下一次机会。 |
| 近距挥爪 | 狮子抬爪，带斜纹的扇区显示约 0.9 秒，随后判定一次，进入约 1.5 秒收招。 | 先退出扇区，再在收招期按助手牵制。阿树从侧边到点，狮子转向助手后开启维护窗口。发动过早会收到「仍在挥爪」，原招式照常结算。 |

两种招式的地面标记与命中使用同一组形状参数。技能栏显示有效条件、冷却和目标状态。条件不符时按键给出短提示并保留冷却可用状态，条件成立才消耗技能并进入约 5 秒冷却。助手执行中显示「阿树前往牵制点」，到点失败会显示原因并复位供重试。牵制期间狮子仍会攻击助手所在方向，玩家穿过预警范围依然可能受击。各时间为原型初值。

## 三步系统修复

每步开始时，HUD 显示当前节点及其所需的成功反制。反制成功后，当前节点才显示「可提交」和倒计时。玩家到节点旁按住 `F` 约 1 秒，由手里的 MacBook 提交该步恢复配置。反制成功和提交完成都有独立反馈。每步只有完成提交才计入「系统修复 0/3」。

| 当前节点 | 玩家如何打开维护窗口 | 提交的系统修复 |
| --- | --- | --- |
| 1 · 识别 | 在入口侧引出一次冲撞，在预警中释放短时麻痹。狮子进入约 3 秒维护状态。 | 写入本地维修凭据，HUD 显示「已验证维修身份」。仍在运行的防御指令继续驱动狮子。 |
| 2 · 隔离 | 在侧边引出挥爪，退出扇区，在收招期释放助手牵制。阿树到点并让狮子换目标后，给约 4 秒。 | 隔离仍在向 L001 下发敌我判定的受感染模块，HUD 显示「感染指令已隔离」。狮子仍执行此前锁存的防御命令。 |
| 3 · 恢复 | 到最后一个节点附近引出冲撞，再次用短时麻痹取消攻击，给约 3 秒。 | 恢复干净的识别配置并清除锁存的防御命令。第三步提交立即停止命中判定，L001 撤销敌对目标、行礼并安全关机。结尾显示「入侵来源：未知」。 |

同一节点的窗口结束前只接受一次提交，连续放技能不会叠加时间或跳步。窗口过期、离开交互范围或受击都会取消本次长按，玩家可以重新引招和反制。摆位验收要求从推荐诱招位置开始，用普通移动就能赶到节点并完成长按。首轮以调整节点距离和窗口时长保证这条路线可读。

## 失败与重试

- 受击扣 2 心并回到当前节点的安全起点，保留已提交的修复步骤、MacBook 和部署的技能。重置本轮狮子招式、助手位置与冷却，恢复后给短暂保护。心值耗尽时选择「重试当前节点」，恢复 10 心并继续。
- 完成每步时保存进度。刷新回到当前节点的安全起点，保留已部署技能和草稿。第三步与通关事实一并保存，刷新或跳过行礼时都进入完成状态。
- 游戏暂停和失焦冻结遭遇计时。工作台只在维护区开放，战中按 `C` 会显示当前技能及返回维护区的提示。回区重编会结束当前交战尝试，已经提交的修复继续有效。

## 可试玩 MVP 与验收

独立入口预置四号楼交接和助手教学已完成，玩家带着 MacBook 从草坪维护区开始，自行编写、测试并部署两项技能。试玩目标约 4–6 分钟，覆盖 L001、两种招式、两项技能、三步修复和一次关机结尾。首轮沿用现有狮身与地面预警原型。移动时由遭遇模块接管狮身碰撞，底座独立处理，避免起点残留静态狮身阻挡。正式流程复用同一遭遇入口。

| 验收项 | 可观察结果 |
| --- | --- |
| MacBook 完整操作 | 玩家用两条不同意图生成两项技能，看到规则差异，跑通有效与无效回放，再把通过测试的版本分别部署。修改选定点位后需重测，旧版本继续可用，测试过程没有推进草坪状态。断开外网可通关。 |
| 玩家主动反制 | 部署后放任狮子出招，技能不会自己释放。玩家在冲撞预警内按键能取消冲撞，过早或过晚会有明确反馈。挥爪命中判定结束后施放，能看见助手到点与狮子换目标。两种攻击都可凭地面提示躲过。 |
| 反击与修复因果 | 错误技能、窗口外或中断长按时进度不变。三次正确反制各自打开指定窗口，完成长按后进度依次变为 1/3、2/3、3/3，并显示相应系统变化。 |
| 恢复与结束 | 在 2/3 受击、耗尽心值或刷新，依然从第三节点继续。完成 3/3 后立即撤掉攻击判定，L001 关机，通关只结算一次。正式开场交接时可核对 MacBook 实例 ID 一致。 |
